# Contributing

Thank you for contributing to this project.

## Workflow

1. Understand the requested change.
2. Make one logical change at a time.
3. Test the change.
4. Update the documentation when necessary.
5. Write a clear commit message.

## Commit Messages

Commit messages should be short and explain the completed change.

Example: `Add input validation`

## Before Submitting

- Confirm the project works.
- Confirm tests pass.
- Remove passwords, tokens, and private information.
- Check that the documentation is accurate.
